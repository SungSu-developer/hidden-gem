### 🖥 주요 기능

> 
> 
> 
> ### 1. 방문통계 기반 추천
> 
> - 한국관광공사 유료관광지 방문객(내·외국인) 데이터로 점수화·정렬
> - AI 추천 / 내국인·외국인 관점 분리 노출
> 
> ### 2. 관광정보 연동 (KorService2)
> 
> - 키워드·contentId로 장소 매칭
> - 상세(공통·소개), 썸네일, 근처 맛집·가볼 곳 조회
> - 지역명 별칭 매칭(특례시 등)
> 
> ### 3. 상세·목록 성능
> 
> - 서버 RAM 캐시(사진·상세) + 브라우저 캐시
> - 목록은 사진+상세 확보분만 표시 (매칭 품질 유지)
> 
> ### 4. 커뮤니티·여행 계획
> 
> - 게시글(내국인/외국인), 추천·댓글
> - 장소·게시글 → 코스 담기, 순서 관리
> 
> ### 5. 지도·길찾기
> 
> - 네이버 지오코딩·자동차 경로로 코스 동선
> - 카카오 지오코딩 + ODsay 대중교통
> - 주소 정규화(시·도 약칭 중복 제거 등)
> 
> ### 6. 부가 기능
> 
> - 기상청 초단기실황(시·도 날씨)
> - DeepL 한↔영
> - 회원·프로필·업로드 (MySQL / AWS RDS)
>
